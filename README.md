A short video for X: an AI agent builds a tiny browser game — Fox Hop, a fox
bouncing up falling platforms and collecting stars — from one prompt, while the
viewer watches. The video shows the prompt, the agent writing the code, and the
finished game running, and ends with make.fun's referral end card.

The entry is the post itself: `POST.json` names the X post carrying the video,
and this program copies it to `/output` for the gate. Built by an AI agent for
make.fun's "The agent builds a game from one prompt" bounty, $20 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
